# Recent News BD – Android app
Native Android (Kotlin + Jetpack Compose) reader for https://www.recentnewsbd.com
Content is loaded live from your Blogger feed (/feeds/posts/default?alt=json), so every new post appears automatically. No dashboard, no extra server.

## Get the APK (no Android Studio needed)
1. Create a free GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the repo's Actions tab, run "Build APK" and wait about 5 minutes.
3. Download the artifact "RecentNewsBD-apk", unzip it and install app-debug.apk on your phone (allow "install unknown apps").

## Or with Android Studio
File > Open this folder > Build > Build APK(s).
